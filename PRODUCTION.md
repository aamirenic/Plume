# PLUME production status

Version 0.1.0. Release commit: `bd6d1ff` (`PLUME: production ready`).
Post-release playtest: 2026-10-28, with fixes committed on top. The
aggressive-behaviour pass (CPU, focus, camera, save/close) also ran on
2026-10-28.

PLUME is a complete, buildable release of the desktop studio, the Rust engine
and the Android shell. This file records exactly what was verified for that
release, the checksums of the built artifacts, and what is still required before
a signed public distribution.

**Readiness statement.** The source tree, the desktop release binary and the
Android debug APK are complete and pass their automated checks. The desktop
binary and APK in the artifact table were rebuilt after the 2026-10-28 playtest
fixes. This is a source-and-debug-build release, not a signed store release: the
Android APK has not been run on a device, and no upload key or store listing
exists. The open items are listed under [Distribution
checklist](#distribution-checklist) and in [BLOCKED.md](BLOCKED.md).

## Build from source

Desktop:

```bash
cargo build --release -p plume-app
PLUME_SOFTWARE=1 target/release/plume      # Windows: set PLUME_SOFTWARE=1
```

Headless render:

```bash
PLUME_SANDBOX="$PWD" target/release/plume \
  --gallery ribbon-bloom --render render.png --width 1200 --height 750
```

Android:

```bash
export ANDROID_NDK_HOME="$ANDROID_SDK_ROOT/ndk/27.2.12479018"
cargo ndk -t arm64-v8a -t x86_64 \
  -o android/app/src/main/jniLibs build --release -p plume-ffi
cd android
./gradlew :app:assembleDebug
```

The native `.so` files and the APK are deliberately ignored by Git; a fresh
clone must build the bridge before assembling. Full format and workflow
documentation is in [README.md](README.md), [docs/FORMATS.md](docs/FORMATS.md)
and [samples/README.md](samples/README.md).

## Scope of this release

- **Desktop:** navigation, pressure-aware curve drawing, RMF frames, guides,
  BVH picking, extrusion, 33 procedural brushes, procedural patterns, liquify,
  mirror, groups, lighting, HDR post-processing, animation, camera shots, and
  OBJ/glTF/STL/USDZ/PNG/GIF/MP4 export plus OBJ/glTF/STL import.
- **Android:** touch authoring, orbit/pinch/pan, brush browser, undo/redo,
  animation scrubbing, autosave, SAF export of supported formats, scene
  gallery, and ARCore tabletop placement. Advanced surface and render controls,
  and full mesh import, remain desktop-only (see [DECISIONS.md](DECISIONS.md)).
- **Interchange:** `.plume` is the native package. `.feather` is a documented
  best-effort interchange format, not native Feather compatibility.

## Distribution checklist

Not done in this pass; each item changes what can be claimed publicly.

- [ ] Install and run the APK on an API 26+ arm64 device or an emulator with
      Google Play services for AR; exercise touch, autosave, SAF export and
      ARCore placement.
- [ ] Create a release keystore outside the repository, configure signing in an
      ignored properties file, and build an AAB.
- [ ] Run the Play pre-launch report; add store listing, screenshots, privacy
      policy and content rating.
- [ ] Verify the desktop build and native dialogs on macOS and Linux.
- [ ] Re-run the render suite on a hardware GPU and record frame timings.
- [ ] Open the generated USDZ in a USD-capable viewer.
- [ ] Test `.feather` import against a lawful sample if one becomes available.
- [ ] Decide whether to add desktop autosave; the current behaviour is explicit
      save plus an unsaved-changes prompt.
