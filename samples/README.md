# PLUME samples

Everything here is generated by PLUME itself. No sample is copied from Feather
or another application.

## Contents

### `documents/`

Four representative authoring documents:

| File | Scene |
| --- | --- |
| `ribbon-bloom.plume` | Layered calligraphic ribbons |
| `wire-flora.plume` | Generative wire plant |
| `neon-knot.plume` | Emissive torus-knot study |
| `terrazzo-tile.plume` | Procedural terrazzo bands |

Each package contains `document.json`, `thumbnail.png` and `manifest.json`.
Open one from the studio, or render it headlessly:

```bash
PLUME_SANDBOX="$PWD" cargo run -p plume-app -- \
  --file samples/documents/neon-knot.plume \
  --render docs/renders/neon-knot.png --quality high
```

### `previews/`

480×300 CPU previews used by the gallery grid and mobile browser. These are the
same preview path the app uses, not separate marketing renders.

### `interchange/`

One file for every external format PLUME writes:

| File | Format |
| --- | --- |
| `ribbon-bloom.glb` | Binary glTF |
| `ribbon-bloom.stl` | Binary STL |
| `ribbon-bloom.usdz` | USDZ |
| `terrazzo-tile.obj` + `.mtl` | Wavefront OBJ with material |
| `terrazzo-tile.feather` | PLUME interchange archive |

The `.feather` file is a PLUME interchange archive, not a native Feather
document. It contains `document.json`, `curves.json`, `thumbnail.png` and a
README explaining the provenance.

## Curated renders

The eight gallery scenes are also rendered at 1200×750 under
[`../docs/renders/`](../docs/renders/). Those images are headless wgpu output,
not CPU previews.

## Regeneration

From the repository root:

```bash
cargo run -p plume-core --example generate_samples
```

The generator is in
[`core/examples/generate_samples.rs`](../core/examples/generate_samples.rs).
It overwrites the documents, previews, interchange files and `testdata/`
fixtures. Timestamps embedded in documents change on each run; geometry is
deterministic.

## Provenance

- Brushes, curves, guides, colours and scene layouts are defined in
  [`core/src/gallery.rs`](../core/src/gallery.rs) and
  [`core/src/brush.rs`](../core/src/brush.rs).
- Thumbnails and previews are drawn by `plume_core::gallery`.
- Meshes are extruded from PLUME curves by `plume_core::extrusion`.
- File writers are implemented in `plume_core::io` from published format
  specifications.

No third-party bitmaps, fonts, icons or scene files are required.
